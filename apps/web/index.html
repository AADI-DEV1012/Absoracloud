How to Join from Minecraft Java Client

  1. Open Minecraft Java Edition (Version 26.3).
  2. Click Multiplayer → Direct Connection (or Add Server).
  3. In Server Address, paste: play.astrocore.qzz.io (No port needed!).
  4. If your DNS client doesn't resolve SRV, you can also join with direct port: bore.pub:25565.
